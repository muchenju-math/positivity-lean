# Coefficient positivity for arborescences of covering digraphs

Fresh Lean 4 formalization of Sections 2–5 of the manuscript. Sections 6 and 7 are excluded. The paper archive stays local and is not included in this repository.

See the module files for finite-fiber systems, loop contraction, vertex elimination, and the induction proof.

Lean toolchain: leanprover/lean4:v4.34.0.
